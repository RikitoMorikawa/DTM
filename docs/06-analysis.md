# 音声解析パイプライン

## 大前提：Claude は音を聴けない

音声ファイルを渡されても BPM もコードも判定できない。
**解析はライブラリが行い、Claude はそれを繋いで JSON にまとめる役割**。

## 環境

```
/Volumes/Logic_Library/_analysis_venv/bin/python     numpy 導入済み
ffmpeg 8.1                                            音声の読み込み・計測
Ghostscript (gs)                                      PDFマニュアルからのテキスト抽出
```

音声の読み込みは ffmpeg で raw float に変換してから numpy で扱う。

```python
subprocess.run(["ffmpeg","-v","error","-i",path,"-ac","1","-ar","22050","-f","f32le","-"],
               capture_output=True).stdout
```

## 導入を推奨するライブラリ

| 用途 | ライブラリ | 精度 |
|---|---|---|
| BPM・ビート・小節頭 | **madmom** (DBNDownBeatTracker) / librosa | 4/4ポップスならほぼ正確。倍/半分の取り違えに注意 |
| キー推定 | **essentia** | 良好 |
| メロディの MIDI 化 | **Basic Pitch** (Spotify) / CREPE / pYIN | 手直し前提 |
| コード認識 | madmom / Chordino | **三和音まで。7th・テンション・分数コードは落ちる** |

現状は numpy のみで自作している（自己相関ピッチ追跡・クロマ・スペクトラルフラックス）。
精度を上げるなら上記を SSD 上の venv に追加する。

## 実測できること（numpy のみ）

| 項目 | 手法 | 実績 |
|---|---|---|
| テンポ | オンセット強度の自己相関 | 82.03 BPM を検出（全オンセットでのグリッドフィットで 81.995 に精緻化） |
| 開始オフセット | グリッドフィットで総当たり | **これを外すと全体がズレる。0.267秒の誤差で終盤0.4秒ズレた** |
| キー | クロマ + Krumhansl プロファイル相関 | C#メジャーを相関0.79で検出 |
| 単音のピッチ追跡 | 自己相関 + 中央値フィルタ + オクターブ補正 | ベース・ボーカルは実用的 |
| 多重音推定 | 倍音加算法 | **精度低い。** 倍音を実音と誤検出、内声を取りこぼす |
| ドラムの打点分類 | オンセット検出 + 帯域エネルギー比 | キック/スネア/ハットの3分類まで。タム・ライドは丸まる |
| ラウドネス | ffmpeg `ebur128` | LUFS / LRA / True Peak |
| 各ステムの音量推移 | RMS の時間変化 | **絶対レベルで見ること**（自身の最大値で正規化すると無音ステムが「常時鳴っている」ように見える） |

## ベースからコードは判定できない

分離済みベースは単音なのでピッチ検出は高精度。ただし**取れるのはルートだけ**。

- メジャー/マイナーの別 → 判別不能
- 7th・テンション → 完全に落ちる
- 分数コード → FonG はルートが G に出るので **G と誤判定する**
- 経過音・シンコペーション → 小節頭だけ拾っても外す

現実的な構成は **ルートをベースから、和音の質を other ステムから**の二段構え。
それでも 7th とテンションは不安定。

**結論：コード進行は U-FRET 等で調べるか、自分で書く。**
既存曲なら解析より調べるほうが速くて正確。

## ステレオ分離の活用

重なったギターは左右に振られていることが多い。
L/R を別々に解析すると分離できる場合がある。

```
L/R 相関 0.465 / Side-Mid比 0.61  → 左右に別々の演奏あり
L だけ 577音 / R だけ 503音 / 両方 139音（センター定位）
```

## 検証を必ず行う

生成した MIDI は、参考音源と同じ指標で測り直して照合する。

```
指標              参考音源   生成物
音符長の中央値      0.25拍    0.24拍   ✅
16分以下の割合      57.0%     58.3%   ✅
同音の反復          15.0%     12.2%   ✅
2度（順次進行）     62.0%     65.7%   ✅
3度以上の跳躍       23.0%     22.2%   ✅
1フレーズの音数     19.8音    17.2音   ✅
休符率             43.0%     44.0%   ✅
表拍から入る割合     22.0%     26.5%   ✅
```

**ただし統計が一致しても音楽的に良いとは限らない。**
モチーフ・反復・展開は別途作曲する必要がある（`rules/composition-rules.md`）。
