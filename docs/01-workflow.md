# 制作フロー

## 目標とする流れ

```
① Suno でスケッチ（アイデア出し）
        ↓  当たりを取る段階で切り上げる
② Demucs でステム分離
        ↓
③ 解析（BPM・キー・メロディMIDI化）        ← ライブラリで自動
   コード進行                              ← U-FRET等で人力 or 自分で作曲
        ↓
④ Ableton に Claude 経由で MIDI 生成・配置
        ↓
⑤ ボーカル：Synthesizer V でガイド作成 → WAV → Ableton
        ↓
⑥ ミックス（人間の耳で判断）
```

## 各工程の担当と、できないこと

### ① Suno — スケッチのみ

完成曲を作らせるのではなく、メロディ・雰囲気・展開の当たりを取る道具として使う。
**曲の骨格が Suno 由来だと権利関係（商用利用・JASRAC登録）が面倒になる**ので、
最終的な進行とメロディは自分で書き直す前提。

### ② ステム分離 — Demucs（CLI）を推奨

Logic Pro のステム分割は GUI 操作が毎回入る。Claude Code がパイプラインにいるなら
`htdemucs` を CLI で回すほうが速く、6ステムモデルも選べる。

**注意：Logic のステム分割は 4パートしか分離しない。**
実際に試した結果、「ピアノ」「その他」のステムは −90dB（実質無音）だった。
分離できていたのは ドラム / ベース / ギター / ボーカル のみ。

### ③ 解析 — Claude は「聴けない」

私は音声ファイルを聴けない。**解析はライブラリが行い、私はそれを繋いで
JSON にまとめるオーケストレーションを担当する。** 詳細は `06-analysis.md`。

| 項目 | 手段 | 精度 |
|---|---|---|
| BPM・ビート・小節頭 | madmom (DBNDownBeatTracker) / librosa | 4/4のポップスならほぼ正確。倍/半分の取り違えに注意 |
| キー推定 | essentia / クロマ+Krumhanslプロファイル | 良好 |
| メロディの MIDI 化 | Basic Pitch / CREPE / pYIN | 手直し前提。ビブラート・しゃくりを余計なノートに分解する |
| コード認識 | madmom / Chordino | **三和音まで。7th・テンション・分数コードは落ちる** |

**コードは人力が正解。** リファレンス曲なら U-FRET や ChordWiki のほうが
どの解析ライブラリより速くて正確（7th もオンコードも書いてある）。

ベースステムからルート音は高精度で取れるが、**取れるのはルートだけ**。
メジャー/マイナーの別も 7th も分数コードも判別できない
（むしろ FonG のような分数コードは G と誤判定する）。

### ④ Ableton へ MIDI 生成

Claude Code → socket:9877 → Remote Script → Live API。
**必ず `rules/ableton-rules.md` を先に読むこと。**

### ⑤ ボーカル

Synthesizer V でガイドを作る。Suno のステムより優れている理由は、
歌詞の発音とタイミングを自分で指定できてクリーンなこと。
歌い手に渡すときは Basic Pitch で MIDI 化 → MuseScore で歌詞付きメロ譜を作る
（演奏用ではなく譜面用）。

**キーは歌う人を決めてから確定する。** 後からキーを変えると Melodyne で移調することになり、
3半音を超えるとフォルマントが破綻して参考にならない。

### ⑥ ミックス — コンピュータユースは向かない

ミックスは「出音を聴いて判断する」閉ループ。GUI を操作できても音は聴けないので、
目隠しでフェーダーを触ることになる。さらに Ableton には Live API があるため、
パラメータを動かすだけなら GUI 操作は不要。

**Claude ができるのは計測と定石の提示まで。**
書き出した 2mix に対して LUFS・True Peak・スペクトルを ffmpeg で実測し、
数値で調整点を出すところまでが担当範囲。判断は耳が持つ。

## 既存曲を再現するとき

`docs/08-cover-pipeline.md` に一気通貫の手順がある（グリッド確定 → 楽器同定 → 採譜 → 音源割当 → タイミング検証 → ミックス → マスター）。
