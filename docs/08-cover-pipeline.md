# 既存曲の再現パイプライン（一気通貫）

iri「Swamp」の再現（2026-09-09〜11）で確立した手順。**私は音を聴けない**ので、
「測る → 数値で設計 → 書き込む → 読み戻して検算」を全工程で回す。

## 0. 前提の確認

```bash
df -h /Volumes/Logic_Library                      # SSD マウント
nc -z 127.0.0.1 9877 && echo MCP OK               # Live 接続
```

Live の環境設定 → Audio の**出力デバイス**を必ず確認（[[03-troubleshooting]]）。

## 1. ステム分割と読み込み

Logic の Stem Splitter で6ステム（ボーカル/ドラム/ベース/ギター/ピアノ/その他）。
**ファイル名は NBSP 区切り**なので `os.listdir` + NFC 正規化 + 末尾一致で解決する。

最初に**全ステムの実レベル**を測り、無音のステムを落とす。

```
piano  RMS -58.2 dBFS / -50dBFS超の時間 3.8%  → 実質無音。ピアノは入っていない
```

### ステムは「5本足してフルミックスに戻るか」で検証してから使う（2026-09-11 の事故）

同じ曲のステムが 2 世代あり（Logic 内の `_ベース.aif` 09-09 と Downloads の `(ベース).wav` 09-10）、
**古いベースは Verse 1 が丸ごと抜けていた**（-93.4 dBFS）。それを目標にしてベースを 11 dB 低く合わせ、
「低音がずっしりしない」と言われるまで気づかなかった。

```
新ステム5本の単純和 → 原曲との残差 -45.6 dBFS   ← 正しい一式
旧ステム5本の単純和 → 原曲との残差 -15.9 dBFS   ← 8.6 dB ぶん欠けている
```

**残差が −40 dBFS 以下になる一式だけを目標にする。** ドラム/ギター/その他/ボーカルは両世代で同一だったので
差分だけ見ても気づけない。必ず和で検算する。

## 2. グリッドの確定（最初にやる。ここを外すと全部ズレる）

1. ドラムのオンセット強度から BPM 候補（librosa は倍/半分を返すので注意）
2. 全オンセットを 16分グリッドに最小二乗フィットして BPM と小節頭を精緻化
3. **オフセットの探索範囲は ±1/32 に制限**する。広げると 16分1つ分ずれた解に落ちて小節番号が狂う
4. 検算：`16分に乗る割合 97%以上 / 平均ずれ 10ms 以下`

```
BPM 101.000 / 1小節目 = 1.2739秒 / 97.4% が ±25%以内 / 平均 8.4ms
```

小節頭の位相は**低域オンセット（キック）と和声変化量**の両方で決める。

## 3. 楽器の同定（帯域配分だけでは当てられない）

| 見たい性質 | 指標 | 目安 |
|---|---|---|
| 歪んでいるか | クレストファクター | クリーン 15-20dB / 強い歪み 6-10dB |
| サステイン | オンセット後 0.3s・0.8s の残り | 生ギター 0.8s後 30-45% / 歪み+コンプ 60%+ |
| 弦楽器か | pYIN の f0 に 4-8Hz の周期変動 | 弓弦 5-7Hz、20-50cent |
| 電子キックか | 低域オンセットの基音と −20dB 減衰時間 | 生 55-80Hz・100-250ms / 電子 40-55Hz |
| 複数本か | L/R 相関と Side/Mid 比 | 相関≒0 かつ Side/Mid≒1 なら**左右が別テイク** |
| 倍音の再検出 | 高音の音名が1つに偏る | 開放弦の倍音。削除か減衰 |

Swamp の実例：ギターは**クレストファクター 9.7dB・0.8秒後 63%・6-10kHz 0.33%**
→ アンプ/キャビを通した歪みエレキ。「その他」は**ビブラート 5.8Hz・同時2音**→ ストリングス。

## 4. 採譜

- **basic-pitch**：本編は `onset 0.62 / frame 0.42 / min 110ms`（断片が半減する）
- **静かな区間は別処理**：切り出して −3dBFS に正規化してから採譜し、**pYIN の音名分布で裏取り**
  （pYIN に出ない音名は削除、D#→E のようなスライドは統合、G# は E コードの第3音なら残す）
- **ベースは pYIN で実音を確認**してから basic-pitch の結果を採用する

### 後処理（実機らしくする）
1. 同音の細切れを結合（隙間 90ms 以内）
2. 短すぎる音を除去
3. 調外の音を除去（局所クロマで裏付けを取る）
4. 打点を 45ms でまとめてストラム化（表拍ダウン=低→高、裏拍アップ=高→低、9ms ずつ）
5. **音の終わりは「次の打点の 20ms 手前」**。「次の打点まで」だと歪みで濁る
6. 弦楽器は**レガート化**：同音を1拍以内で結合 → 声部を実測値まで絞る → 次の打点まで伸ばす

## 5. 音源の割り当て

**音色を数値で作れるのは純正デバイスだけ**（[[ableton-plugin-param-exposure]]）。
外部音源を使う場合は「音源は GUI で選んでもらう / 帯域とダイナミクスは純正で外から作る」の分担。

| 用途 | 選択 | 備考 |
|---|---|---|
| 歪みギター | Kontakt Factory 2 の Elektrik/Jazz + **純正 Amp→Cabinet** | アンプシミュ未所有のため純正で作る |
| ストラム | Electric Sunburst | **パターン専用**。コードを押さえるだけの MIDI を渡す。鍵盤の下半分はキースイッチ |
| ベース | MODO BASS 2 CS | **記譜音**で受ける（[[modo-bass-written-pitch]]） |
| 弦 | Tension「Ensemble Strings」 | 108パラメータを設定可 |
| 電子ドラム | Drum Rack（808/909 Core Kit） | `set_chain_device_param` でパッド個別に設定可 |
| 生ドラム | BFD3 | Core Library は**全53キットがアコースティック**。電子系は無い |

## 6. タイミングの検証（原曲と突き合わせる）

原曲ステムのオンセットと Live の打点を**符号付き**で比較し、系統的なズレを補正する。

```
スネア +6.2ms / ギター +1.7ms / ストラム +1.3ms / ベース −5.8ms  → 許容
ストリングス −25.9ms → +26ms シフトして補正
キック −13.2ms → 補正しない（52Hz が立ち上がるのに 19ms かかる検出側の遅れ）
```

**密度も比較する**。オンセット検出は `delta=0.04` まで下げて公平に。

```
ギター 原曲 5.7打/小節 vs Live 5.3/4.9 → 一致
その他 原曲 3.0打/小節 vs Live 7.6/7.6 → 過密。レガート化で 2.1 に
```

## 6.5 セクション間の強弱（忘れやすい・指摘されやすい）

basic-pitch は音量の大小を拾わないので、**採譜しただけだとセクション間の強弱が原曲と逆になる**。
iri Swamp では実際に逆転していた。

```
           原曲ギター   採譜vel   原曲その他    採譜vel
Intro A     -30.0dB      71     -19.2dB(最大)   97
Verse 1     -25.7        80     -29.0          105 ← 逆転
Chorus 1    -31.0(最小)  91     -22.0           98 ← 逆転
Inter       -19.1(最大)  78     -28.0          109 ← 逆転
```

原曲ステムのセクション別 RMS から係数を作ってベロシティに掛ける。

```python
gain = 10 ** ((section_rms_db - max_rms_db) / 40.0)   # vel 1→127 ≒ 40dB
velocity = clip(original_velocity * gain, 26, 112)
```

掛けたあと、**トラックのコンプが強弱を潰していないか必ず確認**する。
Heavyocity Punish の Compressor / Limiter を有効にすると完全に潰れた。

静かなセクションは採譜自体が薄いので、**区間を切り出して正規化してから採譜し直す**。
ストリングスのイントロは 34音 → 79音になり、低域のルート進行（A2→G2 / F2→E2）が
丸ごと抜けていたことが分かった。

## 7. ミックス

### 音量
原曲ステムの RMS 差を目標にする。**メーターは目盛り値**なので閉ループで合わせる。

```
ドラム 0dB / ベース −5.8 / ギター −14.2 / その他 −13.9 / ボーカル −3.4
```

ゲインは **EQ Eight の Output（実dB）**。トラックフェーダーに setter は無い。
**鳴らない区間で校正しない**（サビで無音のトラックをサビで測ると暴走する）。

メーターの換算式は必ずこれを使う（EQ Output を振って実測したもの）。

```
dBFS = (meter - 0.9018) / 0.2102 * 20        # 0.9018 が 0dBFS、誤差 0.5dB 以内
```

**線形近似（0.011/dB）は約2倍ずれていて、閉ループが全トラックを 12〜25dB 下げてしまった。**
ピーク測定は 1回 ±1.5dB ばらつくので、1dB 以内を追いかけない。
ミキサーのフェーダー上の数字は**メーターのピーク表示**。スクリーンショットが一番確実な検算になる。

### 空間
フルミックスの**帯域ごとの Side/Mid 比**を測って合わせる。

```
20-120Hz  0.00-0.02  → 完全モノラル
120-250   0.11
250Hz以上 0.19-0.24  → 全体 Side/Mid 0.637 / L/R相関 0.816
```

ステム単体が「L/R 相関 ≒ 0」でも、**フルミックスは中央が支配的**。振りすぎない。
低域は Utility の Bass Mono（120Hz）でモノにする。

### マスター
`load_device_on_master` / `set_master_device_param` / `set_master_volume` で操作可。
Utility(Bass Mono) → EQ Eight → Glue Compressor → Limiter。

```
原曲の目標：-8.5 LUFS / LRA 5.1 / True Peak +0.4dBFS / クレストファクター 9.4dB
```

**Live 12 の Limiter は `Maximize On = 1` にしないと `Ceiling` が効かない**（0 だと `Threshold` が効く）。
これに気づかず Ceiling を振り続けて、出力が +1.4dB のままクリップしていた。
**FabFilter Pro-L 2 は 17 パラメータを公開している**ので、純正 Limiter の代わりに使える。

### 検算は Resampling 録音で（メーター推定はここで卒業）

Live の実出力は **Resampling で録音すれば私から測れる**（2026-09-11 に確立）。メーター推定は ±5dB ぶれて収束しない。

1. オーディオトラック `BOUNCE` → `set_input_routing` で **Resampling**、Utility を載せて **Mute=1**（帰還防止）
2. `set_track_arm` → `set_current_song_time` → `start_playback` → **再生開始後に `set_record_mode(True)`**（パンチイン）
   停止中に立てても 1.4 秒の断片しか残らない。読み戻しは常に False だが録音は動く
3. `Samples/Recorded/` に増えた wav の**一番大きいもの**を `ffmpeg ebur128` と numpy で原曲の同区間と比較
   （拍→秒は `(beat-4)*PER+DB`）
4. **パート別 RMS は他トラックを Utility Mute にして単独録音**（原曲ステムと直接比較できる）

iri Swamp サビの実測：Gtr +15.6dB / Strings +6.5dB 過多、Drums −3.1dB。
「ドラムが小さい」の正体は**ピーク基準で揃えたせいでギターが 15dB 出すぎていた**ことだった。

### マスター Glue の罠

Glue（Thr −22 / 4:1 / Range 70）が全体を **15dB 潰し**、EQ Out +10 / Limiter Input 最大でも LUFS が動かなかった。
Resampling の A/B（Glue ON −16.3 / OFF −1.5 dBFS）で判明。
マスターの Glue は `Thr −8 / 2:1 / Range 6 / Out +1` の接着だけにし、**ラウドネスは EQ Eight の Output（実 dB）で
リミッターに押し込む**。+3dB で原曲と一致した（−7.9 LUFS / RMS −6.9 / 全帯域 ±1.8dB）。

## 8. 各工程の検算

| 工程 | 検算方法 |
|---|---|
| グリッド | 16分適合率・平均ずれ |
| 採譜 | 音名分布（調外の割合）、音域、pYIN との一致 |
| タイミング | 原曲オンセットとの符号付き差 |
| 密度 | 打点/小節を原曲と比較 |
| 音量 | `get_track_meters` の閉ループ |
| EQ/コンプ | 書き込み後に読み戻して逆変換 |
| 全体 | 書き出して ebur128 と帯域配分 |

## 9. やりがちな失敗

- **音が出ない → デバイスを疑う前に mute/solo とメーターを読む**
- 外部音源のキーマップを確認せずに転写を流す（MODO BASS で1時間溶かした）
- プラグインのアンロード時に設定ファイルが書き戻され、インデックスがずれる（**名前で引く**）
- BFD3 のプリセットはグルーヴを含み、**MIDI が無くても自動演奏する**
- ユーザーの「〜っぽい」という感想はほぼ正しい。**まず測定で裏を取ってから音源を変える**
- **外部プラグインを「使えない」と決めつけない。** Punish(36) と Pro-L 2(17) は全パラメータを公開している。
  捨てトラックに載せて `get_device_parameters` の数を数えてから判断する
- セクション間の強弱を忘れる（§6.5）

## 10. 原曲へのバランス合わせ（2026-09-11 の追い込み）

### サチュレーターの前でゲインを触っても出力は下がらない

Gtr L/R は `… → EQ Eight → Punish（Saturation ON）` の順。
**EQ Eight の Output を −14 dB したのに実測は −2.5 dB しか下がらなかった。**
非線形段の前を絞っても、サチュレーションが持ち上げ直すため。

→ **レベル合わせは非線形段より後ろで行う。** Punish なら `Out Gain`。
外部プラグインなので実 dB が分からない。**録音 → RMS → 補正の閉ループ**で3回で収束した。

```
Out Gain 0.334 → -24.9 dBFS      目標 -32.0
         0.252 → -29.8
         0.227 → -31.7   収束（Gtr R は 0.173 → -32.2）
```

`Out Gain 0.065`（＝ほぼ絞り切り）で長らく放置されていたのが「ギターが聴こえない」の正体だった。
**閉ループでゲインを触ったら、最後に必ずどこに値が残ったかを読み戻す。**

### 原曲に合わせた結果（音源 bar 1–28.5 / 2026-09-11）

| パート | Live | 原曲 | 差 |
|---|---|---|---|
| ドラム | −11.2 | −10.5 | +0.7 |
| ベース | −27.5 | −27.6 | −0.1 | ← **旧ステムが壊れていた。正しくは −16.2**（§1 の検証を参照） |
| ギター計（L/R/Strum） | −27.6 | −27.8 | −0.3 |
| ストリングス | −22.7 | −22.6 | +0.1 |
| フルミックス | −8.9 | −8.0 | +0.9 |

```
LUFS -9.6 / -8.9    LRA 7.0 / 7.9    True Peak +0.2 / +0.4
Side/Mid 0.230 / 0.319   L/R相関 0.900 / 0.816
帯域は 60-120Hz が -3.8dB 不足、他は ±2dB 以内
```

### Session Guitarist の鳴りっぱなしはエンディングキーで止まる

ブロック最後の和音の **2拍後に A1（MIDI 45）を velocity 20** で置く。
実測：ノート有り小節 −31.8 dBFS / ノート無し小節 **−171.2 dBFS**（完全無音）。

**`get_track_meters` で「止まったか」は判定できない。**
`start_playback` が開始マーカーから一瞬鳴らすので、そこで音源がラッチして
以後ずっと鳴っているように見える。判定は Resampling 録音で。

## 11. 「篭る・楽器が聴き取りづらい」は帯域の取り合いで測る（2026-09-11）

音量を合わせても分離しないときは、**パート別に帯域占有率を測って原曲ステムと比べる**。
Swamp では直感と逆の結果になった。

| | 重心 | 20-60 | 60-120 | 120-250 | 250-500 | 500-1k | 1-2k | 2-4k |
|---|---|---|---|---|---|---|---|---|
| 原曲ギター | 988 | 0.0 | 0.6 | 23.1 | 28.5 | 11.5 | 20.7 | 14.8 |
| Live Gtr L | 931 | 0.0 | 2.2 | 7.8 | 8.5 | **60.4** | 13.4 | 7.3 |
| Live Gtr R | **289** | 0.0 | **24.7** | **57.3** | 4.9 | 8.5 | 3.6 | 1.0 |
| Live Strum | **252** | 0.0 | 13.2 | **73.9** | 6.1 | 2.9 | 2.9 | 1.0 |
| 原曲その他 | 892 | 0.0 | 0.0 | 1.1 | 31.8 | **41.9** | 18.9 | 6.0 |
| Live Synth | **1827** | 0.0 | 0.0 | 0.0 | 3.3 | 15.5 | **51.9** | 25.6 |

- **ギターが暗すぎてベースと同じ場所にいた**（Gtr R / Strum が 60–250Hz に 70–87%）
- **ストリングスが明るすぎて中域の body が空洞**（LowCut が 175–190Hz まで上がっていた）

`10*log10(原曲% / Live%)` が必要補正量。これを EQ Eight のベル/シェルフに割り付ける。
**EQ Eight の正規化値の変換式**（実測で確認済み）:

```
周波数  f = 10 * 2200^v        v = log(f/10)/log(2200)
Q       q = 0.1 * 180^v        v = log(q/0.1)/log(180)
```

## 12. レガート化は発音密度を半分にする

`§4 弦楽器はレガート化` の後処理をかけると、**原曲より打点が半分になり音長が 16 拍まで伸びる**。
「楽器が必要なタイミングで生きてこない」と言われたらここを疑う。

原曲ステムのオンセット密度（打/小節）を測り、**セクションごとに刻み幅を決めて打ち直す**。

```
            原曲   レガート後   刻み直し後   刻み
Chorus 1     8.2      4.6        8.4      1.33拍
Chorus 2     7.5      4.2        7.6      1.00拍
Chorus 3     9.2      4.0        7.8      1.33拍
間奏         2.8      1.2        3.5      6.00拍
Pre 2        0.0      0.0        0.0        -     ← 原曲が無音の区間には打点を作らない
```

音長中央値 1.87 → 0.94 拍 / 最長 16.8 → 3.9 拍。

### サビ直前の上行ランは 1 拍の中にある

iri Swamp では**サビ直前の小節の最終拍だけ**に短音が 3〜4 発入っていて、
レガート化で完全に消えていた。オンセット検出＋HPS で確定した実測値:

```
Chorus1 前  beat 83.02 B2+B3 → 83.33 E3+D4 → 83.76 E3+E4 → 83.96 A2+E4  → サビ頭 A3+E4+A4
Chorus3 前  beat 258.95 B2+B3 → 259.58 G3+C4 → 259.95 E3+E4            → サビ頭 A3+E4+C4
Chorus2 前  0 打（Pre 2 のストリングスは -56.9 dBFS で無音）
```

**セクション単位の平均密度だけ見ていると 1 拍の仕掛けは見つからない。**
サビ・落ちサビの直前 1 小節は必ず個別に拡大して測る。

## 13. 「音の強さが違う」は 6 つの角度で分解する（2026-09-11）

RMS が合っていても「圧が違う」と言われる。同じ区間（音源 bar 5–28.5）でパートごと＋フルミックスを比べる。

| 角度 | 指標 | Swamp で出た差 |
|---|---|---|
| 1. レベル | RMS / ピーク / **クレストファクター** | ベース −12.6dB（旧ステム）、ドラムのクレスト 15.1 vs 12.6 |
| 2. 密度 | 短時間RMS(0.4s)の P10/P50/P90 | ドラムの P10 が 8.5dB 低い＝原曲は静音部も潰している |
| 3. 帯域 | 9 帯域の**絶対** RMS（% でなく dBFS） | ドラム 500Hz–2kHz が −7dB、ストリングス 60–250Hz が −12〜14dB |
| 4. 打点 | オンセット/小節と 0.3s/0.8s 残存率 | ストリングス **1.8 vs 9.7 打**（MIDI は刻んだのに音源のアタックが遅い） |
| 5. 広がり | Side/Mid 全体＋帯域別、L/R 相関 | 0.222 vs 0.301、1–4kHz で 0.40 vs 0.63 |
| 6. ラウドネス | LUFS / LRA / True Peak | −9.7 vs −8.4 |

- **3 は %（配分）でなく絶対 dBFS で出す。** 配分だと「どの帯域がどれだけ足りないか」が dB にならない
- **4 は MIDI でなく録音波形で数える。** 打点を増やしても音源のアタックが遅ければ波形上は増えない。
- **Tension（Ensemble Strings）の `Exc Velocity` は上げてはいけない。** 既定 0.52 → 0.65 にしただけで
  弓のモデルが止まり**完全無音（メーター 0.000）**になる。`Exc Force` 0.75 も同様。アタックはここでは稼げない。
  実測で確認（2026-09-11）。立ち上がりを速くしたいなら Body Decay / Reverb / Glue の Dry/Wet を減らして
  滲みを取るか、刻みの隙間（GAP）を広げて弦を止めてから弾き直す
- 2 のクレスト差はコンプで詰める。Glue の `Threshold` / `Ratio`（0=2:1, 1=4:1, 2=10:1）/ `Dry/Wet`

### ドラムのクレストを詰めるのに速いアタックの Glue を使ってはいけない（2026-09-12）

クレスト 15.1 → 12.6 を狙って Glue を `Attack 0.1ms / 4:1 / Thr −20 / Dry/Wet 1.0` にしたら、
**60–120Hz が −10.9dB、120–250Hz が −8.2dB 落ちてクレストは 16.9 に悪化**した。
キックのエネルギーは低域のトランジェントそのものなので、速いアタックはそこを掴んで潰す。
密度は **Attack 30ms（キックを通す）＋ Output メイクアップ**で RMS を上げ、ピーク側はマスターのリミッターに任せる。
マスターが潰しすぎているかは **LRA と True Peak** で分かる（原曲 LRA 3.8 / TP +0.4 に対し 2.4 / +1.4 なら押しすぎ）。
