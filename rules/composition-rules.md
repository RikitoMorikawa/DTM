# 作曲時の設計指針

## 順序を守る（後から変えると全部やり直し）

1. **歌い手・歌声合成を決める** → 実音域が確定する
2. **キーとテンポを決める** → メロディ最高音がその音域に収まるように
3. **構成を決める**（Intro/A/B/サビ/間奏/D/ラスサビ/Outro）
4. メロディを書く
5. オケを書く

過去、4→2 の順で戻ることになり Logic プロジェクトを2回作り直した。

## 音域の目安

| | 範囲 | 備考 |
|---|---|---|
| Saki AI (Lite) 実用域 | A#3〜E5 (58-76) | F5 (77) が上限の目安 |
| 女性ボーカル一般 | G3〜E5 | サビ最高音 D5〜F5 |
| 男性ボーカル一般 | G2〜G4 | 女性メロディの1オクターブ下 |

**書いた後に必ず実測する。** 度数計算の基準音を間違えると1オクターブずれる。

## 統計を合わせても音楽にはならない

参考曲の音程分布・音符長・跳躍率を一致させても、**モチーフが無ければ単調になる**。
乱数生成ではなく、以下を明示的に作曲すること。

- 2小節のモチーフを作り、反復・変奏する（問い→答え）
- サビのフックは固定して3回とも同じにする
- セクションごとに編成を変える（どの楽器が休むか）
- セクション末尾にフィル、サビ頭にクラッシュ

## 参考曲の扱い

- **コード進行は著作権の対象外**。U-FRET 等で調べて土台にするのは問題ない
- **メロディと歌詞は複製しない**。作風（語彙傾向・譜割り・文末表現）を分析して自分で書く
- ドラム・ベース・コードを丸ごと転写すると、それは「参考にした別の曲」ではなく
  その録音の再現になる。個人の練習ならよいが作品としては成立しない

## 音源選びは音色の性格を確認してから

例：Kontakt Factory Library の **Jazz Guitar** はフルアコ＋フラットワウンドの
シミュレートで、サステインが短く高域が出ない。「コンッ」と鳴るのは仕様。
単音リードには `Guitar Lead` / `Elektrik Guitar` / `Rock Guitar` を使う。
